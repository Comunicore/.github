## 🚀 About Communicore

Communicore is a community-driven platform designed to bring people together through discussions, shared knowledge, and collaboration.

Starting as a modern discussion forum, our long-term vision is to build a social platform where communities can grow, connect, and share ideas.

The project is currently under active development.

## ✨ Features

- User accounts and profiles
- Community discussions, topics, and tags
- Markdown support with syntax highlighting
- Media uploads
- User activity analytics
- Responsive web interface
